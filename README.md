# VK AI-бот (VKBottle + Gemini через ProxyAPI)

ИИ-помощник во ВКонтакте: многодиалоговый режим, 5 режимов общения, краткосрочная память (последние 100 сообщений), хранение в JSON. Домашнее задание «VPf09. Кейс 1: AI-бот в VK», вариант 1.

## Возможности
- Gemini через [ProxyAPI](https://proxyapi.ru) (Google GenAI SDK, настраиваемая модель);
- несколько независимых диалогов: создать, переключить, переименовать, удалить (единственный диалог удалить нельзя);
- 5 режимов (свой system prompt на каждый): обычный помощник, программист, преподаватель, бизнес-консультант, дружелюбный собеседник. Режим действует только в текущем диалоге;
- память: `users/<user_id>.json` — диалоги, режим, сообщения (`role`, `content`, `timestamp`), максимум 100 последних на диалог;
- имитация набора текста, ограничение длины, защита от пустых сообщений, fallback при ошибке API (история при этом не портится);
- LongPoll API, полностью асинхронный код, интерфейс на русском.

## Структура
```
main.py            точка входа
bot/               сборка бота, обработчики, тексты
config/            настройки (.env), режимы общения (prompts.py)
services/          AIService + GeminiProvider, DialogService
models/            UserData, Dialog, ChatMessage
storage/           JsonStorage, MemoryManager
keyboards/         клавиатуры VK
utils/             логгер, работа с текстом, индикатор набора
examples/          прямой запрос к Gemini через ProxyAPI
tests/             pytest (без сети и токенов)
```
Логика AI (`services/`) не зависит от VK (`bot/`, `keyboards/`); провайдер модели подменяется через интерфейс `AIProvider`.

## Запуск
1. Python 3.10+:
   ```bash
   python -m venv venv
   source venv/bin/activate        # Windows: .\venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```
2. ProxyAPI: зарегистрироваться на proxyapi.ru → «Ключи API» → создать ключ (виден один раз!).
3. VK: создать сообщество → Управление → Работа с API:
   - **Long Poll API** — включить, версия 5.199+; в «Типах событий» отметить все пункты раздела «Сообщения»;
   - **Ключи доступа** — создать ключ с правами на сообщения сообщества;
   - Сообщения → Настройки для бота: включить возможности ботов и «Добавить кнопку «Начать»».
4. `cp .env.example .env` и заполнить `VK_TOKEN`, `PROXY_API_KEY` (остальное — по желанию, `GEMINI_MODEL` по умолчанию `gemini-3.1-flash-lite`).
5. `python main.py`, затем написать сообществу и нажать «Начать».

> Запускай ровно один экземпляр бота: второй процесс даст дубли ответов. `.env` в git не попадает — не публикуй токены.

Проверка модели отдельно: `python examples/gemini_proxyapi_example.py` (печатает ответ и расход токенов).
Тесты: `python -m pytest`.

## Отчёт по ДЗ (заполнить после запуска)
- Модель: `gemini-3.1-flash-lite` через ProxyAPI — самая дешёвая из доступных, для чат-бота качества достаточно.
- Расход токенов: _впиши из `usage_metadata` примера или из раздела «Потребление» в кабинете ProxyAPI_.
- Режим для демонстрации: _например, «Преподаватель»_.
- Скриншоты: настройки сообщества (токен скрыт), главное меню, список диалогов, ответ в одном из режимов; файл в `users/`.
