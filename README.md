# VK Math Tutor

Математический репетитор во ВКонтакте: объясняет выбранную тему по шагам, задаёт вопросы, помогает разобрать ошибку и закрепить материал.

**[Отчёт по домашнему заданию со скриншотами](HOMEWORK.md)**

## Возможности

- Класс и тема: например, «7 класс, линейные уравнения».
- Небольшое объяснение → вопрос → самостоятельный ответ → подсказка при ошибке.
- Кнопки «Новая тема», «Объясни проще», «Тест по теме».
- Несколько независимых диалогов с переименованием и переключением.
- Память последних 100 сообщений и отдельное сохранение класса/темы в JSON.
- Пять дополнительных режимов из базового урока.

Python 3.10+, VKBottle, OpenAI-совместимый API. Проверено с aiprimetech и моделью `gpt-6-luna`. Это учебный проект, продолжение AI-бота из урока VPf09.

## Запуск

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.lock.txt
Copy-Item .env.example .env
# Заполните .env своими ключами и ID сообщества
.venv/Scripts/python.exe -X utf8 probe.py --vk
./start.ps1
```

В VK нужны сообщения сообщества, возможности ботов, ключ с правами на сообщения и управление, включённый Long Poll с входящими сообщениями. Используйте один обработчик сообщений для сообщества; отдельно запущенный другой бот может отвечать одновременно.

`probe.py --ai` делает один платный запрос к модели и показывает ответ и расход токенов. `probe.py --vk` читает настройки сообщества без отправки сообщений. Для установки на другой ОС можно использовать `requirements.txt`; зафиксированное окружение проверено на Windows, Python 3.12.

Тесты:

```powershell
.venv/Scripts/python.exe -m pytest -q
```

Результат проверки — 16 тестов пройдены. Подробности и ограничения — в [отчёте](HOMEWORK.md).

## Настройки

Ключ модели, адрес провайдера, модель, VK-токен и ID сообщества задаются в `.env` по шаблону `.env.example`. Не публикуйте `.env`. Папки `users/`, `logs/`, `.vkbottle/` и окружение остаются локальными. Для нового проекта замените ID тестового сообщества своим.

## Ограничения

Только текст, без чтения фото и учебников. Нет автоматической подтверждённой оценки освоения. Объяснения модели могут содержать ошибки. Программа должна оставаться запущенной, чтобы бот отвечал; сервер и автозапуск не включены.
